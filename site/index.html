about this collection

时间范围

严格窗口采用 arXiv 首次公开日期 2025-08-02—2026-08-02；更早论文只在解释趋势不可缺少时作为背景收录。

筛选原则

优先保留能代表架构、训练、系统或评测问题的工作，并标注其与 DiT 的直接、适配、系统或相邻关系。

来源与维护

元数据来自会议官方页面和 arXiv；PDF 按钮直达原始来源。结构化目录和中文笔记在 GitHub 持续维护。
